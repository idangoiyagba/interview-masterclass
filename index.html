6Think about cost, security and reliability

Cost
  • Optimize token usage
  • Use smaller models when possible
  • Cache responses
  • Monitor and set budgets
Security
  • Restrict document access
  • Use secure authentication (SSO)
  • Redact sensitive data
  • Follow data governance policies
Reliability
  • Handle failures (retries, fallbacks)
  • Design for resilience
  • Set SLAs and error budgets
  • Test with real data and edge cases

1Clarify requirements with real numbers

Customers wait hours for a reply. Support costs keep growing. Can an AI assistant answer most questions instantly, and hand off the rest?

Pin down the targets:

  • Traffic? (10k chats/day, 50 req/s peak)
  • Latency? (first token < 1s)
  • Quality? (≥ 85% resolved, no made-up facts)
  • Budget? (< $0.01 per chat)
